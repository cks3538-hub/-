# 오토매크로 (AutoMacro)

MacroDroid처럼 **트리거 → 액션 → 제약 조건**으로 자동화 매크로를 만드는 React 웹앱입니다.

- `index.html` : Claude 아티팩트용 본문
- `app.html` : 그대로 열 수 있는 완성 파일 (휴대폰 브라우저/GitHub Pages용)

## 기능
- 트리거 12종: 시간/요일, 반복 간격, 배터리 잔량, 충전기 연결/해제, 인터넷 연결 변경, 위치(지오펜스), 흔들기, 화면 방향, 앱 화면 진입/이탈, 앱 시작, 바로가기(수동), 변수 값 변경
- 액션 20종: 알림, 팝업, TTS 읽기, 진동, 소리, HTTP 요청, 웹사이트 열기, 변수 설정, If/Else/End If, 대기, 다른 매크로 실행, 매크로 켜기/끄기, 중단, 클립보드, 공유, 화면 켜짐 유지, 로그
- 제약 조건 7종: 시간대, 요일, 배터리, 충전 상태, 인터넷, 화면 방향, 변수 값
- 매직 텍스트: `{time} {date} {weekday} {battery} {charging} {online} {macro} {trigger} {v=변수}`
- 템플릿 9개, 전역 변수, 시스템 로그, 백업/복원(JSON)

## 한계
브라우저 앱이라 **화면이 열려 있는 동안만** 동작합니다. 와이파이·블루투스 끄기, 문자/전화 감지, 다른 앱 실행처럼 안드로이드 시스템 권한이 필요한 기능은 웹에서 불가능하며, 네이티브(React Native) 버전이 필요합니다.
