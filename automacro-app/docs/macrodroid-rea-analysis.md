# MacroDroid 기능 분석 (REA)

REA(reverse-engineer-anything, rea-agents 6.5.0)와 headless JADX 0.7.1로 MacroDroid 6.0.11(com.arlosoft.macrodroid, targetSdk 36)의 APK를 **정적 분석**한 결과입니다.
실행 방법은 `.github/workflows/rea-analyze-macrodroid.yml`에 있습니다. 클래스 이름과 매니페스트 정보만 뽑았고, 디컴파일한 코드는 저장하거나 옮기지 않았습니다.

| 구분 | MacroDroid | 오토매크로 1.1 대응 |
|---|---|---|
| 트리거 | 143 | 22 |
| 액션 | 232 | 39 |
| 제약 조건 | 89 | 19 |

오토매크로 1.1에서 대응하는 항목은 **굵게** 표시했습니다. 나머지는 루팅, 접근성 서비스, Shizuku, 위치 권한, 유료 API가 필요하거나 우선순위가 낮은 항목입니다.
