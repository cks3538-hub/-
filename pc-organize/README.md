# PC 폴더 정리 설계 v3 (Windows)

## 0. 한 줄 원칙
- **고정된 것에만 번호**, 자주 바뀌는 것(프로젝트·연도·행사)은 번호 대신 **상태접두사/날짜**로 정렬한다.
- 폴더 깊이는 **최대 4단계**. 그 이상 필요하면 폴더 대신 **파일명**으로 구분한다.
- 파일명은 항상 `YYYYMMDD_카테고리_내용_v1.확장자`.

## 1. 하위 폴더 넘버링 규칙

| 단계 | 예시 | 번호 붙임? | 이유 |
|---|---|---|---|
| 1단계 (대분류) | `01_진행중`, `02_참고자료` | ✅ 2자리 | 항상 같은 순서로 보이게 |
| 2단계 (고정 하위) | `02_참고자료\02_재무_세금` | ✅ 2자리 | 메뉴처럼 자리가 고정된 폴더 |
| 2단계 (가변 하위) | `01_진행중\0_비더리치_자동화` | ❌ 대신 **상태접두사** `0_`/`1_` | 프로젝트는 생기고 없어지므로 번호를 매기면 금방 깨짐 |
| 3단계 (연도) | `...\02_재무_세금\2026` | ❌ 연도 자체가 번호 | 4자리 숫자라 저절로 정렬됨 |
| 3단계 (행사/이벤트) | `04_사진영상\2026\20260315_부산여행` | ❌ 대신 **날짜접두사** | 날짜순 정렬이 곧 시간순 |
| 프로젝트 내부 | `0_비더리치_자동화\01_기획` | ✅ 고정 템플릿 4개 | 모든 프로젝트가 같은 뼈대를 가지게 |

- 번호는 **01~09** 안에서 끝낸다(10개 넘으면 분류가 너무 잘게 쪼개진 것). `00_`은 "미분류", `09_`는 "기타/도구", `99_`는 "삭제 검토"로 예약.
- 새 폴더가 중간에 끼어야 하면 기존 번호를 밀지 말고 **비어 있는 번호**를 쓴다.

## 2. 최종 구조

```
C:\내PC정리\
├── 01_진행중\                         ← 번호 없음, 상태접두사만
│   ├── 0_비더리치_자동화\             ← 0_ = 진행 중
│   │   ├── 01_기획\                   ← 프로젝트 내부는 고정 템플릿
│   │   ├── 02_자료\
│   │   ├── 03_산출물\
│   │   └── 09_임시\
│   └── 1_세금신고_2025\               ← 1_ = 보류 (재개 시 0_ 으로 이름만 변경)
│
├── 02_참고자료\                       ← "주제 → 연도" 순서 (찾을 때 주제부터 떠올리므로)
│   ├── 00_미분류\2026\
│   ├── 01_업무_비더리치\2026\
│   ├── 02_재무_세금\2026\
│   ├── 03_부동산\2026\
│   ├── 04_법인_사업\2026\
│   ├── 05_강의_학습\2026\
│   ├── 06_개인_생활\2026\
│   └── 09_설치파일_프로그램\          ← 연도 없음 (버전이 곧 구분)
│
├── 03_보관\                           ← "끝난 연도 → 주제" 순서
│   ├── 2023\02_재무_세금\
│   └── 2024-2026_이사준비\            ← 여러 해 걸친 프로젝트는 범위로
│
├── 04_사진영상\                       ← "연도 → 날짜_행사" 순서 (언제 찍었는지로 찾으므로)
│   ├── 00_음악\
│   └── 2026\
│       ├── 20260315_부산여행\
│       └── 20260913_기타\
│
├── 05_기타\                           ← 대기실. 하위 폴더 금지. 20개 넘으면 비우기
└── 99_삭제_검토\                      ← 바로가기·임시파일·중복. 한 달 뒤 통째로 삭제
```

### 왜 폴더마다 "주제/연도" 순서가 다른가
| 폴더 | 순서 | 찾을 때 머릿속 질문 |
|---|---|---|
| 02_참고자료 | 주제 → 연도 | "세금 자료 어디 있지?" |
| 03_보관 | 연도 → 주제 | "그거 몇 년도에 끝났더라?" |
| 04_사진영상 | 연도 → 날짜_행사 | "작년 봄에 찍은 거" |

## 3. 파일명 규칙

```
YYYYMMDD_카테고리_내용_v1.확장자
20260913_세금_종합소득세신고서_v1.pdf
```
- 날짜 8자리 맨 앞 (정렬 = 시간순)
- 공백 대신 `_`, 금지문자 `\ / : * ? " < > | # % &`
- 버전은 `v1, v2, final` — "최종", "진짜최종" 금지
- 사진은 `20260315_IMG_0001.jpg` 처럼 날짜만 붙이고 원래 이름 유지 (카메라 번호가 곧 순서)

## 4. 운영 규칙 (이게 없으면 다시 어질러짐)
1. **매주 금요일 5분**: `05_기타`, `다운로드` 폴더 비우기 → 02/03/04 중 하나로 보내거나 삭제
2. **프로젝트 상태 변경 = 이름만 변경**: `0_` ↔ `1_`. 폴더 이동 없음
3. **03_보관 이동은 분기 1회**: 완전히 끝난 프로젝트만, "끝난 연도" 폴더 밑으로
4. **99_삭제_검토는 한 달 뒤 통째로 삭제** (한 달 동안 안 찾았으면 필요 없는 것)
5. **바탕화면에는 바로가기 3~5개만** — 파일은 두지 않는다

## 5. 진행 순서
1. `pc_scan.ps1` 실행 (읽기 전용) → `바탕화면\PC정리_분석결과\분석요약.txt` 확인
2. 요약을 보고 주제 폴더/키워드 조정
3. 실제 이동 스크립트 실행 (별도, 승인 후 / 미리보기 + 되돌리기 로그 포함)
4. DropIt 으로 다운로드 폴더 자동 분류 규칙 설정
